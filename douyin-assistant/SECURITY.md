# 安全与隐私

- 浏览器 CDP 绑定 loopback；不对公网开放。它仍可能被同机其他进程访问，请只在可信单用户环境使用。
- 不关闭 Chromium 沙箱，不隐藏自动化，不绕过验证码、频控或账号异常。出现风控立即停止相关操作，无自动风控重试。
- 本地状态在 `runtime/data/`，包括浏览器配置、Cookie/登录信息、截图、任务数据库、网页文字和评论。HOME 由启动器隔离到 `runtime/data/home/`；这不是操作系统安全沙箱或加密边界。
- 截图和网页内容可能含个人资料。不要将 data、日志、运行输出、授权策略、素材或浏览器状态发到公开仓库；支持请求只提供人工脱敏的最小复现。
- 未配置授权时禁用发布/回复；专用最终提交写入持久记录。结果未知或遗留 dispatched 先人工核对远端，绝不自动重新提交。
- 上游源代码保留供追溯；不要直接运行其维护/升级脚本替换经过审查的固定版本。runtime 禁用了后台更新 worker。
- Python/npm 安装会访问软件源；imageio-ffmpeg 依赖可能自带 FFmpeg 二进制，各自许可适用。仓库不包含安装后的依赖、字体或浏览器。
- `.gitignore` 不是秘密扫描或访问控制。发布前仍必须只打包审核过的源码白名单。

## 本次实测后的边界

- Windows profile 路径现在遵守 `DOUYIN_SKILLS_HOME`；不能依赖 Windows 的 `HOME` 改写来改变 `Path.home()`。本次登录前检查了实际浏览器参数和项目内 profile。固定 CDP 端口若已被其他浏览器占用，连接复用仍缺少通用 profile 归属校验；开始新会话前须核对端口与进程，不连接日常浏览器。
- 回复编辑器和发送按钮限制在已匹配的评论卡片内；找不到唯一作者/目标/编辑器时停止。短信核验可能使 `contenteditable` 变为 false；这类禁用草稿仍必须从成功证据中排除。检测到核验后不自动重连、刷新、获取验证码或发送。
- 当前页回复回显不能独立证明平台接受。没有可靠回执或独立复核时保留 `uncertain`，不自动重复。旧记录若因历史缺陷误判为 confirmed，须保留原记录并附上纠正说明；不要通过删除记录恢复可发送状态。
- 当页面没有稳定评论 ID 时，评论 key 包含呈现文字，可能随时间/页面刷新变化。账本仅保证同一 key 的去重，不能承诺跨刷新语义去重。AI 必须结合既有任务和远端内容判断，不使用变化后的 key 重新提交。
- policy 中工作量/预算字段是运营约束，不应理解成执行器实现了全局计费或限额防火墙。默认禁用发布/回复；范围内也需遵守当前用户授权。
